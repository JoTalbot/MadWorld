# B10 Google Play Readiness

Repository-side checklist only. No store submission is claimed.

- [ ] Final application ID and version selected.
- [ ] Release signing key/keystore managed outside Git and backed up securely.
- [ ] Production HTTPS API URL configured for release build.
- [ ] Privacy Policy URL available and legally approved.
- [ ] Data Safety declaration matches actual collection/sharing.
- [ ] Account/data deletion process documented where applicable.
- [ ] Content rating and target audience completed.
- [ ] App icon, screenshots and store listing prepared.
- [ ] Android API/device matrix executed.
- [ ] Crash reporting and analytics privacy basis verified, if used.
- [ ] Push notifications verified, if enabled.
- [ ] Release artifact checksum/provenance retained.
- [ ] Production rollback and incident ownership confirmed.

A green GitHub build is necessary but not sufficient for Play publication.
