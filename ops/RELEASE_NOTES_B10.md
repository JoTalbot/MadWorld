# MadWorld — B10 Release Notes

## Release candidate scope

MadWorld's production candidate combines the authoritative gameplay, economy, social, territory, dynamic-world, finance, Android, security and operations foundations delivered through B1–B9.

## Player-facing highlights

- Dynamic world simulation with persistent consequences
- Regional economy and player-driven market foundations
- Vehicle, combat, salvage and recovery gameplay
- Territory, corporations, alliances and warfare
- NPC faction activity and world events
- Finance and asset provenance
- Android authoritative state, offline queue and reconnect/resume
- Notifications, analytics and LiveOps foundations

## Operational highlights

- Production API/worker/migrator topology
- PostgreSQL migration and backup/restore procedures
- Health checks and bounded rate limiting
- Load-test and device-matrix contracts
- Recovery and rollback procedures

## Release caveat

Environment-dependent production controls, physical-device verification, legal/privacy sign-off, external crash/analytics provider configuration and final capacity approval must be verified by the release owner before public launch. They are not inferred from repository code.
